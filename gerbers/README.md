# FC4MSX Gerber Production Files

Place the manufacturing Gerber zip files and drill files here.

### Standard Fabrication Files
- `*.GTL` - Top Copper
- `*.GBL` - Bottom Copper
- `*.GTS` - Top Solder Mask
- `*.GBS` - Bottom Solder Mask
- `*.GTO` - Top Silkscreen
- `*.GBO` - Bottom Silkscreen
- `*.GKO` / `*.GML` - Board Outline / Mechanical Layer
- `*.DRL` / `*.TXT` - NC Drill file

Alternatively, provide a ready-to-upload ZIP file:
`FC4MSX_Gerbers_vX.X.zip`
